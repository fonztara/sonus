# sonus

**sonus** is a lightweight macOS utility that acts as a customizable personal soundboard. It's designed to always run in the background and be available instantly via a global keyboard shortcut. With Sonus, you can quickly record or upload sounds, name them, and play them at any time just by typing their name.

## Features

- 🔊 Play audio clips by typing their name
- ⌨️ Trigger everything from a global keyboard shortcut
- 🎤 Record audio or upload your own files
- 📝 Rename and manage sounds in a simple UI
- 🪟 Minimal NSWindow-based interface that stays out of your way
- 🖥️ Runs quietly in the background, always ready

## How It Works

1. Launch Sonus — it runs silently in the background.
2. Press the global keyboard shortcut `Control + Z` to bring up the **sonus** window.
3. In the window, you can:
   - Record a new sound using your microphone.
   - Upload an existing audio file (e.g., MP3).
   - Rename sounds to make them easier to trigger.
4. Start typing the name of a sound — it will instantly play.

## Use Cases

- For fun: play memes or jokes on cue
- For work: trigger audio cues or notifications during meetings
- For accessibility: create custom audio actions tied to situations or feedback
- For streamers: a quick personal sound pad

## Installation

This is a personal project and not yet distributed via the Mac App Store. To try it out:

1. Clone the repo:
   ```
   git clone https://github.com/fonztara/sonus.git
   ```
2. Open the project in Xcode.
3. Build and run the app.
